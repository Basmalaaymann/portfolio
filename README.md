## ✨ Features

- 🎨 **Modern gradient design** with dark/light mode auto-detection (`prefers-color-scheme`)
- ⌨️ **Animated typing effect** cycling through roles (AI Engineer, Data Scientist, etc.)
- 🎯 **Interactive project demo** — click stages of the Agentic RAG pipeline (Query Rewriter → Retriever → Generator)
- 📱 **Fully responsive** — mobile-first layout with safe-area insets for notched devices
- ♿ **Accessible** — keyboard focus outlines, `aria-live` regions, `prefers-reduced-motion` support
- ⚡ **Zero dependencies** — pure HTML, CSS, and vanilla JavaScript (no build step, no frameworks)
- 🚀 **Scroll-reveal animations** via `IntersectionObserver`
- 🧊 **Glassmorphism cards** with backdrop blur
